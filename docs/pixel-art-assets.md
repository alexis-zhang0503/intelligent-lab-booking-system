# Pixel art assets

All files in `assets/pixel/` are original project SVGs created for V3 and use only the local 6-colour palette: `#090D17`, `#121826`, `#314A6C`, `#4673A9`, `#5686FF`, `#76C9D4` plus neutral text. They use `shape-rendering="crispEdges"` and are locally loaded; no external image or commercial artwork is included.

| Asset | Purpose |
|---|---|
| `laboratory.svg` | Isometric laboratory opening subject |
| `terminal.svg` | workstation node |
| `calendar.svg` | reservation node |
| `instrument.svg` | scientific equipment node |
| `ai-scheduler.svg` | resource scheduling node |

Pixel Lab informed the local, export-ready Pixel SVG format; it is not required at runtime.
