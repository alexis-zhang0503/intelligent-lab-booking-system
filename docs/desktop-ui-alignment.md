# 桌面端 UI 与“我的”页面更新

> 历史归档：本文涉及已移除的 Qt 客户端，不属于最终交付。请改用 [最终 Windows 桌面端说明](desktop-c-client.md)。

## 问题与调整

原发布包的 Qt 客户端只有英文单页仪表盘，学生预约列表挤在设备平面图下方；网页端已有中文多页面导航与个人中心。新版 Qt 将导航、配色、卡片、提示文案调整到网页端的视觉方向，并新增独立个人中心。

| 页面 | 本次调整 |
| --- | --- |
| 登录 | 中文品牌文案、登录与注册卡片、中文账号提示 |
| 预约 | 日期和时段、40 台设备状态、选择汇总、查看我的预约入口 |
| 我的 | 姓名和身份、今日预约、常用设备与时段、未来预约、包括取消记录的历史 |
| 签到签退 | 历史表展示预约状态、实际签到时间、实际签退时间和实际使用时长；选中记录后启用相应操作 |
| 时长 | 预约小时与实际使用时长分开计算 |
| 故障 | 学生查看自己的报告；管理员查看报告、解决故障和导出 |
| 管理 | 总览、设备、用户分页，保留设备维护、注销学生及文件导出 |

所有预约和签到时间按 Asia/Shanghai（北京时间）显示。取消记录不再因为使用仅返回有效预约的接口而从历史列表消失。未签到的到期预约显示为“已结束 · 未签到”，不会显示成已完成使用。

刷新直接更新已存在的页面，保留有效选中项；页面切换保留各自滚动位置。退出登录时停止定时器并断开旧控件连接，再释放旧页面，避免跨账号残留。

## 验收步骤

1. 按 Qt 客户端说明构建并运行 CTest。启动程序注册学生，或登录已有本机账号。
2. 查看“预约 / 时长 / 故障 / 我的”导航；进入“我的”，确认无预约时有空状态和去预约入口。
3. 预约明天的设备，进入“我的”，核对日期、设备和时段；选中该记录应允许取消、禁止提前签到。
4. 取消预约后确认历史仍显示“已取消”，并且设备时段可重新预约；今日与偏好统计不计入该取消记录。
5. 到达一条预约的时段后选中该记录签到，再签退，确认实际时间与实际时长显示，并更新时长页面。预约结束而未签到的记录应禁用签到。
6. 点击刷新、来回切换页面，确认选中项保留；退出后换账号登录，确认不显示前一账号的预约。
7. 管理员检查总览、设备、用户和故障页，验证导出及维护操作仍可用。
8. 在最小窗口尺寸和常用 Windows 缩放比例下查看布局，确认表格可横向滚动、内容可纵向滚动。
