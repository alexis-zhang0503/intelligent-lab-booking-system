# UI design tokens

The V3 tokens live in `design-system/tokens.css`. They define background, surface, ink, muted ink, accent, cyan, border, radii, spacing, elevation and motion roles. Components consume semantic roles such as `--v3-surface` and `--v3-border`, avoiding one-off colour values in the V3 UI layer.

The palette is a dark scientific SaaS scheme: base `#090D17`, surface `#121826`, primary ink `#F5F7FA`, muted ink `#9AA8BE`, accent `#5686FF`, cyan `#76C9D4`.
